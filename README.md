# Plugin HTML

## Introduction

The `plugin-html` plugin provides the ability to create portlets containing HTML content within Lutece pages. It offers two types of portlets:

 
*  `HTML_PORTLET` — An HTML portlet whose content is cleaned by the `HtmlCleanerService` before being stored. The output is rendered through the XSL transformation pipeline (standard Lutece portlet rendering).
*  `HTML_UNTRANSFORMED_PORTLET` — An HTML portlet whose content is stored and rendered as-is, without any HTML cleaning or XSL transformation. This is useful whenyou need full control over the HTML output.

Both portlet types share the same administration interface and the same database table ( `html_portlet` ), but differ in their rendering behavior.

## Configuration

The plugin uses two Spring beans injected via `SpringContextService.getPluginBean` :

| Bean ID| Interface| Description|
|-----------------|-----------------|-----------------|
|  `htmlPortletDAO` |  `IHtmlPortletDAO` | DAO for the HTML portlet (with HTML cleaning)|
|  `htmlUntransformedPortletDAO` |  `IHtmlPortletDAO` | DAO for the untransformed HTML portlet (without HTML cleaning)|

These beans must be declared in the plugin's Spring context so that the `HtmlPortletHome` and `UntransformedHtmlPortletHome` classes can retrieve them at startup.

## Usage

Once the plugin is activated, two new portlet types become available in the Lutece back-office when adding portlets to a page:

 
*  `HTML Portlet` — provides a rich text editor (WYSIWYG) for entering HTML content. The content is cleaned using Lutece's `HtmlCleanerService` before being saved to the database. The portlet output goes through the XSL transformation pipeline, applyingthe configured stylesheet (default or colored background style).
*  `Untransformed HTML Portlet` — provides a plain text area for entering raw HTML. The content is stored exactly as entered and rendered without any XSL transformation.This is suitable for embedding scripts, iframes, or any HTML that should not be altered.

Two XSL styles are available for the standard HTML portlet:

 
* Default style — renders the HTML content inside a standard portlet container.
* Colored background style — renders the HTML content inside a `well` container with a colored background.

The portlet administration is handled by the `HtmlPortletJspBean` class, which manages the creation, modification, and display of both portlet types through a singleinterface, adapting its behavior based on the portlet type identifier.
