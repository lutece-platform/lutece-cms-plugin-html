# Plugin HTML

## Introduction

Le plugin `plugin-html` permet de créer des portlets contenant du contenu HTML au sein des pages Lutece. Il propose deux types de portlets :

 
*  `HTML_PORTLET` — Un portlet HTML dont le contenu est nettoyé par le `HtmlCleanerService` avant d'être enregistré. Le rendu est effectué via le pipeline de transformation XSL (rendu standard des portlets Lutece).
*  `HTML_UNTRANSFORMED_PORTLET` — Un portlet HTML dont le contenu est enregistré et affiché tel quel, sans aucun nettoyage HTML ni transformation XSL. Cela est utilelorsque vous avez besoin d'un contrôle total sur le rendu HTML.

Les deux types de portlets partagent la même interface d'administration et la même table en base de données ( `html_portlet` ), mais diffèrent dans leur comportement de rendu.

## Configuration

Le plugin utilise deux beans Spring injectés via `SpringContextService.getPluginBean` :

| Identifiant du bean| Interface| Description|
|-----------------|-----------------|-----------------|
|  `htmlPortletDAO` |  `IHtmlPortletDAO` | DAO pour le portlet HTML (avec nettoyage HTML)|
|  `htmlUntransformedPortletDAO` |  `IHtmlPortletDAO` | DAO pour le portlet HTML non transformé (sans nettoyage HTML)|

Ces beans doivent être déclarés dans le contexte Spring du plugin afin que les classes `HtmlPortletHome` et `UntransformedHtmlPortletHome` puissent les récupérer au démarrage.

## Usage

Une fois le plugin activé, deux nouveaux types de portlets sont disponibles dans le back-office Lutece lors de l'ajout de portlets à une page :

 
*  `Portlet HTML` — propose un éditeur de texte riche (WYSIWYG) pour saisir du contenu HTML. Le contenu est nettoyé par le `HtmlCleanerService` de Lutece avant d'être enregistré en base de données. Le rendu du portlet passe par le pipelinede transformation XSL, appliquant la feuille de style configurée (style par défaut ou fond coloré).
*  `Portlet HTML non transformé` — propose une zone de texte brut pour saisir du HTML. Le contenu est enregistré exactement tel que saisi et affiché sans aucunetransformation XSL. Cela convient pour intégrer des scripts, des iframes ou tout HTML qui ne doit pas être modifié.

Deux styles XSL sont disponibles pour le portlet HTML standard :

 
* Style par défaut — affiche le contenu HTML dans un conteneur de portlet standard.
* Style fond coloré — affiche le contenu HTML dans un conteneur `well` avec un fond coloré.

L'administration des portlets est gérée par la classe `HtmlPortletJspBean` , qui assure la création, la modification et l'affichage des deux types de portlets via une interfaceunique, en adaptant son comportement en fonction de l'identifiant du type de portlet.
